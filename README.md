# Graduation Invitation - Triệu Quang Sáng

Project React/Vite thiệp mời tốt nghiệp, giữ nguyên intro phong bì màu xanh và thay sticker cũ bằng hiệu ứng pháo hoa CSS.

## Nội dung đã cấu hình

- Tên: Triệu Quang Sáng
- Trường: Trường Đại học Công nghệ Đông Á
- Địa điểm: Nam Từ Liêm, Hà Nội
- Thời gian: 15:00 ngày 07.08.2026
- Lời mời dùng chung cho tất cả khách; chỉ tên khách thay đổi theo URL

## Chạy project

```bash
npm.cmd install
npm.cmd run dev
```

## Link cá nhân

```text
/?guest=ban-than
/?guest=gia-dinh
/?to=Nguyễn%20Văn%20A
```

Danh sách khách demo nằm trong `src/data/guests.js`.

## Trang quản lý link demo

```text
/?admin=1
```

## Google Form và Google Drive

Thay cấu hình `GOOGLE_FORM` và `galleryUrl` ở đầu file `src/main.jsx`.
